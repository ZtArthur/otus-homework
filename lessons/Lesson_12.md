## Описание / Пошаговая инструкция

### Пункт 1. Интеграция `SimpleStore` в `TcpServer`

Возьмите класс `TcpServer` из ДЗ №2 и класс `SimpleStore` из ДЗ №3. Модифицируйте `TcpServer` так, чтобы он создавал и хранил один экземпляр `SimpleStore`. Лучше всего передавать экземпляр хранилища через конструктор сервера.

***

### Пункт 2. Реализация логики обработки команд

В методе `ProcessClientAsync` после парсинга команды добавьте блок `switch` (или `if/else if`), который будет определять, какую операцию выполнить. Внутри этого блока вызывайте соответствующие методы вашего экземпляра `SimpleStore` (`Set`, `Get` или `Delete`). Не забудьте корректно преобразовывать данные:

- из `ReadOnlySpan` в `string` — для ключей
- из `ReadOnlySpan` в `byte[]` — для значений (`span.ToArray()`)

***

### Пункт 3. Формирование и отправка ответа для `SET` и `DELETE`

После успешного выполнения команд `SET` и `DELETE` сервер должен отправить клиенту подтверждение. Сформируйте простой ответ, например, строку `"OK\r\n"`. Преобразуйте эту строку в `byte[]`:

```csharp
Encoding.UTF8.GetBytes("OK\r\n")
```

и отправьте клиенту с помощью:

```csharp
await clientSocket.SendAsync(...)
```

***

### Пункт 4. Формирование и отправка ответа для `GET`

После выполнения команды `GET` возможны два исхода:

- Если `_store.Get(key)` вернул значение (`byte[]`) — отправьте эти байты клиенту
- Если метод вернул `null` (ключ не найден) — отправьте клиенту стандартизированный ответ, например, строку `"(nil)\r\n"`

***

### Пункт 5. Обработка некорректных команд

Добавьте в блок `switch` ветку `default` для обработки всех неизвестных команд. В этом случае сервер не должен падать, а должен отправить клиенту сообщение об ошибке, например:

```
-ERR Unknown command\r\n
```

***

## Критерии оценки

| Критерий | Баллы |
|---|:---:|
| Экземпляр `SimpleStore` корректно создаётся и используется внутри `TcpServer` | 1 |
| Реализована логика для команд `SET` и `DELETE`, включая вызов методов хранилища и отправку ответа `"OK"` клиенту | 3 |
| Реализована логика для команды `GET`, включая отправку найденного значения или стандартизированного `"null"` ответа | 3 |
| Сервер корректно обрабатывает неизвестные команды, отправляя клиенту сообщение об ошибке, и не падает | 2 |
| Все необходимые преобразования типов данных (`Span` в `string`, `Span` в `byte[]`, `string` в `byte[]`) выполнены корректно | 1 |
