# Домашнее задание: сериализация UserProfile в SimpleStore

## Описание/Пошаговая инструкция выполнения домашнего задания

### Пункт 1. Создание модели данных (DTO)

Создайте простой `public class UserProfile`. У него должно быть как минимум три свойства разных типов, например: `public int Id { get; set; }`, `public string Username { get; set; }`, `public DateTime CreatedAt { get; set; }`. Этот класс будет нашей моделью данных.

### Пункт 2. Модификация интерфейса SimpleStore

Измените сигнатуры методов в вашем классе `SimpleStore`. Теперь они должны работать с `UserProfile`, а не напрямую с `byte[]`:

- `void Set(string key, UserProfile profile)`
- `UserProfile Get(string key)`

Внутреннее хранилище `Dictionary<string, byte[]>` остается без изменений.

### Пункт 3. Реализация сериализации и десериализации

Внутри метода `Set` используйте `System.Text.Json.JsonSerializer.SerializeToUtf8Bytes(profile)` для преобразования объекта `UserProfile` в `byte[]` перед сохранением в словарь. Внутри метода `Get` после получения `byte[]` из словаря используйте `JsonSerializer.Deserialize(bytes)` для преобразования данных обратно в объект.

### Пункт 4. Обновление логики TCP-сервера

Модифицируйте метод `ProcessClientAsync` в `TcpServer`. Теперь, когда приходит команда `SET`, ее `VALUE` часть является JSON-строкой. Вы должны взять этот `ReadOnlySpan`, представляющий JSON, и десериализовать его в объект `UserProfile` (`JsonSerializer.Deserialize(valueSpan)`), прежде чем вызывать метод `_store.Set()`.

### Пункт 5. Обновление клиента для нагрузочного теста

Модифицируйте TCP-клиент, который вы использовали в ДЗ №5. Теперь при отправке команды `SET` он должен сначала создать экземпляр `UserProfile`, сериализовать его в JSON-строку, а затем отправить эту строку как `VALUE` часть команды. Это необходимо, чтобы проверить работоспособность всей цепочки.

## Критерии оценки

| Критерий | Баллы |
|---|---|
| Создан класс-DTO `UserProfile` с несколькими свойствами разных типов | 1 |
| Интерфейс `SimpleStore` изменен для работы с `UserProfile`, а не с `byte[]` | 2 |
| В `SimpleStore` корректно реализована логика сериализации в `Set` и десериализации в `Get` с помощью `System.Text.Json` | 3 |
| Логика `TcpServer` обновлена для десериализации входящего JSON-значения при выполнении команды `SET` | 2 |
| Клиентская часть (например, для нагрузочного теста) обновлена для отправки сериализованных в JSON объектов, что доказывает работоспособность всей системы | 2 |
